1. Deskripsi Praktikum

Praktikum ini membangun aplikasi WebGL2 interaktif untuk menerapkan translation, rotation, uniform scaling, non-uniform scaling, dan komposisi Model Matrix. Geometry hanya dibuat sekali dalam local coordinate dan disimpan di satu vertex buffer. Posisi, sudut, dan ukuran setiap objek dibentuk sepenuhnya oleh Model Matrix mat3 yang dikirim ke vertex shader sebagai uniform u_model — data vertex asli tidak pernah diubah.

Tiga objek memakai kembali satu vertex buffer yang sama: Object A (dikontrol keyboard/mouse), Object B (animasi otomatis), dan Object C (child dari B). Selain itu, Object A digambar dengan dua urutan transformasi sekaligus agar perbedaan hasil visualnya bisa langsung diamati.

2. Tujuan Praktikum

Setelah menyelesaikan praktikum ini, mahasiswa diharapkan mampu:

  1. Membedakan local coordinate dan world coordinate.
  2. Membuat matriks translation, rotation, dan scaling dalam bentuk 3×3 (homogeneous coordinate 2D).
  3. Menyusun Model Matrix dengan perkalian matriks dan memahami bahwa urutan perkalian mengubah hasil.
  4. Mengirim matriks ke vertex shader sebagai uniform mat3.
  5. Memakai ulang satu geometry untuk banyak objek dengan Model Matrix yang berbeda.
  6. Membuat input keyboard berbasis state dengan deltaTime agar gerak konsisten di berbagai frame rate.
  7. Membangun hubungan parent–child dan orbit sederhana lewat komposisi matriks.

Perbandingan Transform Order

3. Dua Urutan Transformasi

Keduanya memakai parameter yang sama (translation, rotation, scale) dan geometry yang sama. Karena perkalian matriks tidak komutatif, hasil visualnya berbeda begitu rotation dan translation tidak nol. Matriks di bawah ini dihitung langsung dari state Object A dan ikut berubah saat kamu menggerakkannya.

Order 1 — Scale → Rotate → Translate

M = T · R · S
Objek diskala dan diputar terhadap pusatnya sendiri, baru dipindahkan. Posisi di layar sama dengan nilai translation.

-

Order 2 — Scale → Translate → Rotate

M = R · T · S
Objek diskala, dipindahkan, lalu seluruh hasilnya diputar terhadap origin (0,0) sehingga objek mengorbit: posisi di layar berubah mengikuti rotation.

-

Cara Mengamati

  • Tekan 2 (Stretch) lalu tahan Q — pada Order 1 panah berputar di tempatnya, pada Order 2 panah berputar mengelilingi origin.
  • Garis putus-putus dari origin ke pusat objek memperlihatkan jarak pusat objek ke origin: tetap pada Order 2 saat rotation berubah, dan sama dengan jarak translation pada Order 1.
  • Tekan T untuk menukar urutan mana yang menjadi objek utama dan mana yang menjadi bayangan.

4. Fitur Pilihan yang Dikerjakan

Minimal dua fitur pilihan diminta. Kelompok kami mengerjakan lima dari enam fitur:

Reset Transform (R)

Selesai
Tekan R atau tombol Reset Transform

Mengembalikan position, rotation, dan scale Object A ke nilai awal dalam satu aksi event-based (sekali tekan, e.repeat diabaikan).

Tiga Transform Preset

Selesai
Tekan 1, 2, atau 3

Preset 1 (Orbit), Preset 2 (Stretch, non-uniform scale 2.2 × 0.6), dan Preset 3 (Big Tilt, uniform scale 1.6). HUD menampilkan preset aktif dan kembali ke manual begitu nilai diubah.

Toggle Transform Order (T)

Selesai
Tekan T atau tombol Toggle Order

Menukar M = T·R·S dan M = R·T·S. Order aktif tampil di HUD, dan order lawannya tetap terlihat sebagai bayangan.

Translation dengan Mouse

Selesai
Klik atau drag pada canvas

Posisi pointer dikonversi dari pixel ke world coordinate lewat getBoundingClientRect(). Pada Order 2, posisi dunia dikembalikan ke parameter translation dengan R(−θ) agar objek tepat berada di bawah kursor.

Parent–Child & Simple Orbit

Selesai
Object C mengikuti Object B (P untuk on/off)

Model Matrix child dibentuk dari matriks parent: M_C = M_B · R(orbit) · T(r,0) · R(spin) · S(0.45). Saat B bergerak, berputar, dan berdenyut, C ikut bergerak sambil mengorbit dan berputar sendiri.

6. Checklist Pengujian

Sebelum dikumpulkan, pastikan hal-hal berikut sudah terpenuhi:

  • Scene WebGL2 memiliki minimal dua object yang memakai vertex buffer yang sama (A, B, dan C).
  • Geometry disimpan dalam local coordinate; posisi, rotasi, dan ukuran hanya lewat Model Matrix 3×3 (u_model).
  • Translation, rotation, uniform scaling, dan non-uniform scaling bekerja.
  • Object A dikontrol keyboard secara kontinu (state-based) dengan deltaTime.
  • Object B beranimasi otomatis (rotation + scaling).
  • Dua urutan transformasi menghasilkan tampilan yang berbeda dan dapat diamati.
  • HUD menampilkan position, rotation, scale, dan transform order aktif — dan selalu mengikuti perubahan.
  • Sumbu X, sumbu Y, dan origin (0,0) terlihat.
  • Gerak konsisten pada frame rate berbeda (coba pilihan 30 FPS dan 15 FPS).
  • Tidak ada error merah pada Console pada penggunaan normal.

7. Ringkasan Praktikum

  • Local coordinate vs world coordinate
  • Matriks 3×3: T(tx,ty), R(θ), S(sx,sy)
  • Komposisi matriks — urutan perkalian menentukan hasil
  • Uniform mat3 ke vertex shader lewat gl.uniformMatrix3fv
  • Satu vertex buffer dipakai ulang oleh banyak objek
  • State-based keyboard + deltaTime untuk gerak yang tidak bergantung frame rate
  • Parent–child transformation dan orbit sederhana
